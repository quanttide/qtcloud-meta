# qtcloud-meta 命令行

qtcloud-meta CLI 是量潮元云的本地命令行入口，把[《三层极简架构方案》](../../../docs/index.md)的两条重点流程做成可执行工具：本体写入与范畴分析。本文档组按雪花写作法从主文档分解而来，本页只留全局与导航。

## 在平台中的位置

两条流程在命令行这一侧的口径：

1. 本体写入：数据源主要是规格；命令行只提供本体录入格式与校验入库，不提供 LLM，抽取与整理在进入命令行之前完成。变更落库后由人类在审批页面确认，批准才写入 Turtle/OWL 本体文件。
2. 范畴分析：先把本体和关系作为对象和态射装进范畴里，按范畴的标准方法做范畴论分析，得到一系列关系作为报告返回，LLM 拿这份报告做进一步分析。分析遵循既定规则，不是 LLM 猜；五步过程见[范畴](user-guide/category.md)。

## 现状

`src/cli` 是 Rust 骨架：包 `qtcloud-meta-cli` v0.1.0，二进制 `qtcloud-meta`，运行仅输出一行名称。当前没有任何命令设计——两版设计（七个命令、单个 `change submit`）都已删除，行为定义以主文档为准，接口何时重做见[API 参考](api-references/index.md)。
