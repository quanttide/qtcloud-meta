# qtcloud-meta 命令行

qtcloud-meta 是**系统的元认知工具**。写资料的 AI 没有连续的记忆，写下的资料容易概念不一致；这套命令把「什么算一致」立成概念体系，拿它照系统写下的资料。

命令行照两面：

- **范式照结构**：本体装进范式做数学校验，两个域之间查映射表翻译断言；
- **属性照字段**：字段用法对着标准属性表逐条核，不合的、标准没收的各出一份清单。

两面都只读表、只出报告，判断由读报告的人做。本体写入目前只有方案，命令还没做——现有命令不写任何东西。
