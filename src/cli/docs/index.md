# qtcloud-meta 命令行

qtcloud-meta CLI 是量潮元云的本地命令行入口，把[《三层极简架构方案》](../../../docs/index.md)的两条重点流程做成可执行工具：本体写入与范畴分析。本文档组按雪花写作法从主文档分解而来，本页只留全局与导航。

## 在平台中的位置

主文档的两条流向落在命令行上：

1. 本体写入：非结构化输入 → LLM 抽取 → 对齐本体 → 本体变更（待审批）→ 人类确认 → 写入本体文件生效；CLI 在本地触发并执行这条链路，人类确认仍在审批页面完成。
2. 范畴分析：分析任务 → 选定范畴 → 跨范畴映射翻译 → 冲突裁决 → 输出整合结论；CLI 查询映射、执行翻译并输出结论。

## 现状

`src/cli` 是 Rust 骨架：包 `qtcloud-meta-cli` v0.1.0，二进制 `qtcloud-meta`，运行仅输出一行名称。两条流程的命令尚未实现，行为定义以主文档为准，用法与命令参考随实现补充。
