# 范式的使用过程

范式的使用分两个层次，不混在一起：一个范式内部怎么装载与分析，以及从一个范式怎么走到另一个范式。

| 层次 | 范围 | 对应 | 状态 |
| :-- | :-- | :-- | :-- |
| [范式内](within.md) | 单个范式 | 装载 → 分析 → 返回 | Rust 演示已实现 |
| [范式间](between.md) | 从一个范式走到另一个范式 | 选定 → 映射 → 冲突 → 缺失 → 结论 | 步骤骨架已实现，规则未定义 |

[范式内](within.md)讲本体与关系怎么装进范式、按标准方法分析、出一份关系报告；[范式间](between.md)讲跨范式导航的五步，规则内容尚未定义，这一层不代拟。

全局结构见[用户指南](../index.md)，范式三表的结构见主文档[开发指南](../../../../../docs/dev-guide/index.md)。
