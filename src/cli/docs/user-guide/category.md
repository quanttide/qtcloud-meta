# 范畴的使用过程

本体及关系录入系统之后，范畴的性质分析遵循一定的规则，不是 LLM 猜测。规则具体有哪些尚未定义，本页不代拟：范畴三表（`category`、`category_mapping`、`conflict`）的结构见主文档[开发指南](../../../../docs/dev-guide/index.md)，流程的全局结构见[用户指南](index.md)。

## 装载与分析

1. 装载：先把本体和关系分别作为对象和态射装进范畴里。
2. 分析：按范畴的标准方法做范畴论分析，得到一系列关系。
3. 返回：把这系列关系作为报告返回。

CLI 出报告，LLM 拿这份报告做进一步分析。

## 过程

范畴之间怎么走，按主文档定义的五步：

1. 选定范畴：确定当前范畴，读出它的本体承诺。
2. 映射翻译：查 `category_mapping` 取映射规则，按规则把断言翻到目标范畴。
3. 冲突检查：查 `conflict` 比对既往裁决，`true_conflict` 记录按既往裁决处理。
4. 规则缺失：生成一条 `change_request` 等人类定义规则，分析暂停在当前范畴。
5. 输出结论：给出目标范畴下的整合结论，回传元智能体。
