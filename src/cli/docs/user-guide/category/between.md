# 范畴间：五步走

这是「范畴之间怎么走」，也就是跨范畴导航。按主文档定义的五步执行，本页不代拟规则；步骤骨架的代码在 [`examples/category/between.rs`](../../../examples/category/between.rs)。

## 五步

1. 选定范畴：确定当前范畴，读出它的本体承诺。
2. 映射翻译：查 `category_mapping` 取映射规则，按规则把断言翻到目标范畴。
3. 冲突检查：查 `conflict` 比对既往裁决，命中 `true_conflict` 的按既往裁决处理。
4. 规则缺失：没有规则时生成一条 `change_request` 等人类定义，分析暂停在当前范畴。
5. 输出结论：给出目标范畴下的整合结论，回传元智能体。

## 三张表在哪一步被用到

- `category`：第 1 步读本体承诺；
- `category_mapping`：第 2 步查映射规则；
- `conflict`：第 3 步比对既往裁决，`true_conflict` 是按既往裁决处理的那种记录。

表结构见主文档[开发指南](../../../../../docs/dev-guide/index.md)。

## 边界

规则具体有哪些尚未定义，本页不代拟——第 2、3 步的「按规则」「按既往裁决」目前是接口，不是实现。本页只保证步骤顺序与职责边界，不保证步骤内部的规则内容。
