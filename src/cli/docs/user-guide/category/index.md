# 范畴的使用过程

范畴的使用分两个层次，不混在一起：一个范畴内部怎么装载与分析，以及从一个范畴怎么走到另一个范畴。

| 层次 | 范围 | 对应 | 状态 |
| :-- | :-- | :-- | :-- |
| [范畴内](within.md) | 单个范畴 | 装载 → 分析 → 返回 | Rust 演示已实现 |
| [范畴间](between.md) | 从一个范畴走到另一个范畴 | 选定 → 映射 → 冲突 → 缺失 → 结论 | 步骤骨架已实现，规则未定义 |

[范畴内](within.md)讲本体与关系怎么装进范畴、按标准方法分析、出一份关系报告；[范畴间](between.md)讲跨范畴导航的五步，规则内容尚未定义，这一层不代拟。

全局结构见[用户指南](../index.md)，范畴三表的结构见主文档[开发指南](../../../../../docs/dev-guide/index.md)。
